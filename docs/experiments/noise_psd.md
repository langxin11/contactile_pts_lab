# 传感器噪声本底与功率谱密度 (PSD) 分析

本实验通过对传感器在空载稳态下的高频采样数据进行傅里叶变换与 Welch 功率谱密度（PSD）估计，分析接触传感器各柱体的物理噪声频段分布，为软件数字滤波（如一阶低通滤波器截止频率 $f_c$）的选型与调优提供定量依据。

---

## 1. 分析背景与理论依据

### 1.1 硬件抗混叠滤波与采样
根据原厂手册 `PTS_2.1_SPEC` §5.1：
- 传感器内部前端对每路模拟信号配置了硬件一阶抗混叠低通滤波器（$-3\text{ dB}$ 频点约为 $235\text{ Hz}$，在 $1000\text{ Hz}$ 采样下截止频率约为 $338.8\text{ Hz}$）。
- 控制器 ADC 以最高 $1000\text{ Hz}$ 对 9 个传感柱（共 36 路光电二极管信号）进行同步采样。

### 1.2 为什么需要 PSD 分析
在实际机器人操作中，过低的低通截止频率会导致触觉反馈延迟增大、抓握滑移判定滞后；过高的截止频率则会残留高频高斯噪声与工频干扰，导致力控抖动。
通过 PSD 曲线与**累积能量积分曲线**，可直观获知：
- 白噪声与工频纹波主要分布在哪个频段。
- 设定不同截止频率 $f_c$ 时，能保留多少信号能量、滤除多少噪声功率。

---

## 2. 实验步骤

### 2.1 数据采集要求
1. 传感器必须置于无振动、无气流、无物理接触的平稳台面上。
2. 上电并完成无负载 Bias 清零（零点校准）。
3. 持续采样采集 10~60 秒，生成包含 $T_{us}$ 时间戳列的 CSV 文件（例如运行自研协议采集或中继比对生成的 `protocol.csv`）。

### 2.2 运行分析工具

在 `python_ws` 目录下运行：

```bash
uv run --extra plot python noise_psd_analysis.py \
    ../data/protocol_compare/<会话目录>/protocol.csv \
    --sensor 0
```

### 2.3 输出图表与终端指标

脚本会在 CSV 同级目录下生成两张高分辨率科研图表：
1. `<文件名>_psd.png`：各传感柱 $F_x, F_y, F_z$ 的功率谱密度曲线，标明硬件抗混叠频点。
2. `<文件名>_psd_cumulative.png`：截止频率 vs 残余噪声能量曲线。
3. 并在终端打印各频段（如 0~10Hz, 10~50Hz, 50~100Hz, >100Hz）的能量占比百分比，辅助选定滤波参数。
