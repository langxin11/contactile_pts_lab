# 传感器电气特性、噪声底测量与软件一阶低通滤波

> 基于原厂手册 PTS_2.1_SPEC_JAN25、PTSCTR_2.0_SPEC_DEC21、PTSDK_2.0_MAN_DEC21、PTSCOM_2.0_SPEC_SEP22 的中文总结，并结合实际工程讨论整理。

## 1. 电气与采样特性

### 1.1 信号链（数据流总览）

```
硅胶柱形变 → 4 路光电二极管信号
   └─> [硬件抗混叠低通滤波器]          §5.1
        └─> ADC 采样（最高 1000 Hz，16-bit）  §5.2
             └─> 控制器解码/校准
                  （原始光电 → 3D 位移/3D 力，含扭矩、滑移、摩擦计算）
                   └─> USB 虚拟串口 → 主机（闭源 API）
```

- 每个传感柱（pillar）有 **4 个光电二极管**，信号经光学转导测量柱顶端的 **3D 位移**，再经出厂标定换算为 **3D 力**。
- 控制器在**传感器侧**完成解码与校准，主机通过**闭源 API** 读取校准后的位移/力（以及全局力/力矩、滑移状态、摩擦估计）。

### 1.2 采样特性

| 参数 | 数值 | 出处 |
|------|------|------|
| 单柱最高采样率 | **1000 Hz，16-bit 全分辨率** | PTS_2.1 §5.2 |
| 可选采样率（串口命令 `f100/f250/f500/f1000`） | 100 / 250 / 500 / 1000 Hz | PTSCOM |
| 每传感器柱数 | 9（3×3 阵列），2 传感器共 18 柱 | PTS_2.1 |
| 主机数据速率 | 与采样率一致，经 USB 虚拟串口 | PTSCTR |
| 位移量程/分辨率 | X,Y ±1 mm；Z +2.5 mm；分辨率 < ±0.01 mm | PTS_2.1 §4.1 |
| 力量程/分辨率 | Fx,Fy ±4 N；Fz 15 N；分辨率 < ±0.05 N | PTS_2.1 §4.2 |
| 温度补偿 | 内置部分补偿，但必须软件 Bias 清零 | PTS_2.1 §4.3 |

### 1.3 硬件抗混叠滤波器（唯一明确的滤波）

| 参数 | 数值 |
|------|------|
| 类型 | **硬件（模拟）低通滤波器**，在 ADC 之前 |
| 截止频率 | **338.8 Hz**（对应 1000 Hz 采样） |
| -3dB 点（图 5.1） | **235 Hz** |
| 作用对象 | 每个传感柱的 **4 路光电二极管信号** |

**为什么要"硬件"：** 抗混叠必须发生在模数转换之前。一旦超过奈奎斯特频率（fs/2）的高频成分被采样"折叠"（aliasing）进低频，之后任何数字滤波都无法复原。采样 1000 Hz → 奈奎斯特 500 Hz，模拟滤波器在 500 Hz 之前就压住高频，保证采样不失真。

### 1.4 使用要点

- **每次使用前 Bias 清零**：抵消零负载偏移与温度漂移，属校准而非滤波。
- 采样率选项只影响采样密度，**不改变硬件抗混叠滤波器的物理截止频率**。
- 手册未提及控制器/SDK 内部存在额外数字滤波；可确认的只有上述硬件抗混叠。SDK 内部为黑盒，是否含未文档化处理无法从手册排除。

## 2. 噪声底测量（无负载数据 + 频谱分析）

### 2.1 用途

对**无负载**记录的数据做功率谱密度（PSD）分析，能回答 4 类问题：

1. **认识噪声频段分布** —— 是平坦白噪声，还是集中在某个频段？决定软件滤波"是否值得做、往哪里滤"。
2. **发现周期性干扰** —— 如 50 Hz 工频、USB/采样伪影产生的尖峰（频谱上表现为离散谱线）。
3. **验证硬件抗混叠** —— 应看到噪声在 ~235–340 Hz 附近开始滚降；若没有，说明数据链路有问题。
4. **为软件低通选 fc 提供依据** —— 由"截止频率 fc 以上的可移除噪声能量占比"曲线，定量选择 fc。

### 2.2 采集方法

| 步骤 | 要求 |
|------|------|
| 1. Bias 清零 | 先发 bias，等读数归零、稳态 |
| 2. 环境 | 传感器**无负载、不触碰**，远离振动源，温度稳定 |
| 3. 采样率 | 用 **1000 Hz** |
| 4. 时长 | **10–60 s**（越长，低频分辨率和谱估计越稳） |
| 5. 输出 | 含 `T_us` 时间戳的 CSV（同 `protocol.csv` / `sdk.csv` 格式），间隔均匀 |

### 2.3 分析方法

- **用 Welch 平均周期图，不要用单次 FFT**：单次 FFT 的谱估计方差极大（曲线剧烈起伏），Welch 分段加窗平均后平滑可信。
- 分析前需**去线性趋势 + 去均值**（否则直流/漂移分量泄漏污染整个谱）。
- 频率分辨率 ≈ fs / nperseg；fs=1000 Hz、nperseg=1024 时约 1 Hz。
- 仓库已有实现：`python_ws/noise_psd_analysis.py`（numpy 手写 Welch，不依赖 scipy）。

### 2.4 结果解读

| 谱形态 | 含义 | 对滤波选择的影响 |
|--------|------|------|
| 整体平坦（白噪声底） | 噪声均匀分布 | fc 的选择纯看"平滑 vs 延迟"权衡 |
| 235 Hz 附近开始滚降 | 硬件抗混叠生效，链路正常 | 软件低通无需超过 ~200 Hz 追求"干净" |
| 50 Hz 处离散尖峰 | 工频干扰 | 低通能压，但若干扰来自接地环路应优先解决源头 |
| 极低频能量高（漂移） | 温度/偏置漂移 | **低通滤不掉**，只能靠 Bias/高通处理 |

### 2.5 局限性

- **无负载测的是"电子噪声底"**；加载后光电信号电平变化，实际噪声水平可能有差异。选 fc 时应留余量，并在真实工况下验证。
- 只能测到 **API 输出**的噪声；SDK 内部黑盒处理无法用该方法探测。
- 若时间戳不均匀（丢帧），谱会失真，需先确认间隔均匀。

## 3. 软件一阶低通滤波

### 3.1 含义

一阶低通（单极点 IIR / 指数平滑）是最简单的递归滤波器：当前输出 = 输入与上一次输出的加权平均。

**差分方程：**
```
y[n] = α·x[n] + (1-α)·y[n-1]          （0 < α ≤ 1）
等价形式：y[n] = y[n-1] + α·(x[n] - y[n-1])
```
- `x[n]` 当前输入，`y[n]` 当前输出，`y[n-1]` 上一次输出；
- `α` 越接近 1 → 越跟手、越不平滑；`α` 越接近 0 → 越平滑、越滞后；
- 每个采样点只需一次乘加，适合实时在线处理。

### 3.2 系数公式（截止频率 ↔ α）

给定期望截止频率 `fc` 和采样率 `fs`：

```
α = 1 - exp(-2π·fc / fs)
```

当 `fc << fs` 时可用近似：`α ≈ 2π·fc / fs`

**fs = 1000 Hz 时的对应关系：**

| fc (Hz) | α | 等效时延 τ≈1/(2πfc) |
|---------|------|------|
| 10 | 0.061 | ~16 ms |
| 20 | 0.118 | ~8 ms |
| 50 | 0.269 | ~3.2 ms |
| 100 | 0.467 | ~1.6 ms |
| 200 | 0.715 | ~0.8 ms |

### 3.3 频率响应与代价

- **幅度响应**：`|H(f)| = 1 / √(1 + (f/fc)²)`，在 `f = fc` 处幅度衰减到 70.7%（-3dB）。
- **相位滞后**：`φ(f) = -arctan(f/fc)`，低频时近似线性，等效群延迟 `τ ≈ 1/(2π·fc)`。
- **核心权衡**：截止频率越低 → 越平滑，但**延迟越大、真实动态信号被衰减越多**。

### 3.4 截止频率选择指南

| 应用场景 | 建议 fc | 理由 |
|---------|---------|------|
| 静态/准静态力读取稳定化 | **5–20 Hz** | 读数平稳无抖动，接受 ~10–30 ms 延迟 |
| 力控闭环反馈 | **20–60 Hz** | 保持动态响应又不抖 |
| 保留滑移/接触瞬态 | **100–200 Hz** | 滑移、触碰是高带宽信号，轻滤波 |
| 振动/纹理/动力学分析 | **不滤波** | 关心的正是高频成分 |

> ⚠️ 若使用控制器的滑移检测（Slip Detection），不要把 fc 压到 100 Hz 以下，否则会抹掉滑移特征。数据若用于 ML / 离线分析，**保留原始数据**，滤波只放应用层（滤波不可逆）。

### 3.5 用噪声底测量选 fc（推荐流程）

1. 采集无负载数据，算 PSD（见第 2 节）；
2. 看"理想低通可移除的 fc 以上噪声占比"曲线，选一个能压掉大部分噪声、又不低于所需动态带宽的频率；
3. 在真实加载工况下验证：滤波后信号是否仍能反映你关心的触觉事件（接触、滑移、力变化率）。

> 上述占比使用理想砖墙低通估算；实际一阶低通在 fc 之后逐渐衰减，不会完全删除高频能量，因此必须在真实工况下复测。
